how to add or change IDs

  1. go to cloudflare dashboard → pages → flowtongshu-landing → settings → variables & secrets
  2. add or edit any of: META_PIXEL_ID, META_CAPI_TOKEN, GOOGLE_ADS_ID, GOOGLE_ADS_LABEL, TIKTOK_PIXEL_CODE, TIKTOK_ACCESS_TOKEN — mark as secret
  3. save — values propagate to the edge within ~30 seconds
  4. hard refresh this page, fire a test event, watch the platform's events manager for arrival (usually under 30s)

note: the cf /api/config response is edge-cached for 60s — if a change doesn't show, wait a minute or hard-refresh.

attribution between this landing & app.flowtongshu.com is handled by the fts_clk cookie + appending click ids to outbound cta urls. the app must read fts_eid from its query string and pass it as the event_id when firing the conversion event server-side. that closes the loop.
